# Weather CLI App

Просмотр текущей погоды и автоматическое ведение истории запросов через консольное приложение на Python.

## Описание проекта

Приложение запрашивает данные о погоде через API, определяет текущие координаты пользователя, форматирует вывод и сохраняет результаты в локальное хранилище.

Архитектура модуля history.py:
* Интерфейс WeatherStorage позволяет менять или добавлять новые типы хранилищ.
* Класс PlainFileWeatherStorage сохраняет дату и отформатированный отчет в простой текстовый файл.
* Класс JSONFileWeatherStorage записывает историю запросов в JSON-файл в формате ключ-значение.

## Структура проекта

* weather — главный исполняемый файл для запуска приложения.
* weather_api_service.py — модуль для взаимодействия с внешним API погоды.
* weather_formatter.py — модуль для форматирования и отображения погоды в терминале.
* coordinates.py — модуль для определения текущих геокоординат.
* config.py — конфигурационный файл для хранения настроек и ключей доступа.
* exceptions.py — кастомные ошибки приложения и обработка исключений.
* history.py — архитектура хранилища и логика работы с историей запросов.
* history.json / history.txt — автоматически создаваемые файлы с историей поиска.

## Стек технологий

* **Python 3.10+** (используется современная аннотация типов, встроенные модули json, pathlib, datetime).
* Проект использует **только стандартную библиотеку Python**, установка сторонних пакетов через pip не требуется.

## Установка и запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com
cd ИМЯ_РЕПОЗИТОРИЯ
```

### 2. Настройка конфигурации
Откройте файл config.py и добавьте ваш API-ключ для сервиса погоды.

### 3. Запуск приложения
Запустите главный скрипт через терминал:
```bash
python weather
```
