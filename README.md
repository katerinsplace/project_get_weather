# Weather CLI App 🌤️

Простое, модульное консольное приложение (CLI) на Python для получения текущей погоды и автоматического ведения истории запросов.

## 🚀 Описание проекта

Приложение запрашивает данные о погоде через API сервиса погоды, определяет текущие координаты пользователя, форматирует вывод в красивый человекочитаемый вид и сохраняет результаты в локальное хранилище.

### Ключевые особенности архитектуры (`history.py`):
* **Гибкое логирование:** Реализован ООП-интерфейс (`WeatherStorage`), позволяющий легко менять или добавлять новые типы хранилищ.
* **Текстовые логи (`PlainFileWeatherStorage`):** Логирование даты и отформатированного отчета о погоде в простой текстовый файл.
* **JSON логи (`JSONFileWeatherStorage`):** Структурированное сохранение истории запросов в JSON-файл в формате ключ-значение (с поддержкой `TypedDict`).

## 📁 Структура проекта

* `weather` — главный исполняемый файл для запуска приложения.
* `weather_api_service.py` — модуль для взаимодействия с внешним API погоды.
* `weather_formatter.py` — модуль для форматирования и красивого отображения погоды в терминале.
* `coordinates.py` — модуль для определения текущих геокоординат.
* `config.py` — конфигурационный файл (хранение настроек и ключей доступа).
* `exceptions.py` — кастомные ошибки приложения и обработка исключений.
* `history.py` — архитектура хранилища и логика работы с историей запросов.
* `history.json` / `history.txt` — автоматически создаваемые файлы с историей поиска.

## 🛠️ Стек технологий

* **Python 3.10+** (используется современная аннотация типов, встроенные модули `json`, `pathlib`, `datetime`).
* Проект написан на **стандартной библиотеке Python** — устанавливать сторонние пакеты (`pip install`) не требуется!

## ⚙️ Установка и запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com
cd ИМЯ_РЕПОЗИТОРИЯ
```

### 2. Настройка конфигурации
Откройте файл `config.py` и добавьте ваш API-ключ для сервиса погоды (если применимо).

### 3. Запуск приложения
Запустите главный скрипт через терминал:
```bash
python weather
```
*(Или просто `./weather` в системах Linux/macOS, если файлу выданы права на исполнение).*
